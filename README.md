# RetailCheck — Retail Intelligence & Demand Forecasting

RetailCheck is a data analytics project focused on retail transaction analysis, customer segmentation, and product demand forecasting.

## Key Features
- Data cleaning and preprocessing of retail transactions
- SQL-based analytics using PostgreSQL
- RFM customer segmentation and cohort retention analysis
- Demand forecasting using statistical and machine learning models
- Interactive Power BI dashboard for visualizing insights

## Tech Stack
**Python · Pandas · NumPy · PostgreSQL · SQL · Scikit-learn · Power BI · DAX**

## Getting Started
1. Clone the repository.
2. Install the required Python dependencies.
3. Configure the database connection.
4. Run the data processing and analysis scripts.
